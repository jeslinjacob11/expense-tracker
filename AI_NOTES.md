# AI Usage Notes

## AI Tool Used

- ChatGPT

---

## 1. Which parts of the code were AI-generated vs. written by me?

The overall project idea, project structure, feature selection, and implementation approach were decided and developed by me.

I implemented the application myself using FastAPI, HTML, CSS, and JavaScript. AI assistance was used mainly to clarify concepts, resolve errors, debug issues, and provide guidance when I encountered implementation challenges.

AI also helped with generating portions of documentation such as the README and improving code organization where needed.

---

## 2. What did I validate, test, or change?

I reviewed and validated all AI-assisted suggestions before incorporating them into the project.

Specifically, I:

- Tested every API endpoint using FastAPI Swagger UI.
- Debugged routing, import, and frontend integration issues.
- Modified and customized the dashboard layout and styling.
- Updated the filtering, search, and chart functionality to fit my project requirements.
- Verified that JSON storage worked correctly.
- Wrote and executed automated tests using pytest.
- Confirmed that all required assignment features were working before submission.

Any AI-generated suggestions that were used were first tested and, where necessary, modified to match my implementation.

---

## 3. Any AI suggestion you decided not to use?

Yes.

I chose not to implement several suggestions because they were outside the scope of the assignment, including:

- Database integration (SQLite/PostgreSQL)
- User authentication
- React frontend
- Docker deployment
- Cloud deployment
- Additional advanced analytics features

The assignment required a lightweight REST API using local JSON storage, so I kept the implementation aligned with those requirements.

---

## 4. Personal Contribution

The majority of the project development was completed by me, including:

- Planning the project structure.
- Implementing the API.
- Integrating the frontend with the backend.
- Debugging application issues.
- Testing the application manually.
- Running and validating automated tests.
- Organizing the project files.
- Preparing the final submission.

AI was primarily used as a development assistant for troubleshooting, explaining concepts, and resolving errors rather than designing the project itself.
